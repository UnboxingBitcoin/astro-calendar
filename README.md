# Krishna Mukh Astro Calendar

Planetary ingresses, aspects, retrograde/direct stations, eclipses and new/full moons, in sidereal (Lahiri) and tropical zodiacs, Indian time (IST).

- 12 Nov 2023 – 12 Nov 2029: every event
- 1959 – 2050: eclipses and slow planets (Jupiter–Pluto, Chiron, Rahu/Ketu)
- 1500 – 2100: Saturn, Uranus, Neptune, Pluto

Data from Swiss Ephemeris, checked against NASA eclipse catalogues, astro.com and panchang tables. See the Method tab on the page.
